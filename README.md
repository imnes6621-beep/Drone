# DRONE BUILDER (ประกอบโดรน • ออกบิน • เข้าใจระบบ)

ระบบจำลองการออกแบบ ประกอบ และบินโดรน 3 มิติ (3D Drone Engineering & Flight Simulation) พัฒนาตามต้นแบบ UI ครบทุกฟังก์ชัน 100%

---

## 🚀 วิธีการเปิดใช้งาน (How to Run)

คุณสามารถเปิดใช้งานได้ 2 วิธีง่ายๆ:

### วิธีที่ 1: ดับเบิลคลิกไฟล์ `start-game.bat` (แนะนำ)
1. เปิดโฟลเดอร์ `c:\โปรเจค`
2. ดับเบิลคลิกไฟล์ **`start-game.bat`**
3. ระบบจะเปิดเว็บเบราว์เซอร์และเริ่มเกมที่ `http://localhost:3000` ทันที!

### วิธีที่ 2: รันผ่าน Command Line
```powershell
cd c:\โปรเจค
agy-node.cmd server.js
```
แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

## 🎮 ระบบและหน้าจอทั้งหมดในโปรเจค (Features & Screens)

### 1. หน้าแรก (Home Screen)
- **3D Preview Interactive Window**: พรีวิวฉาก 3 มิติลานบิน หุบเขาหิมะ และโดรนกำลังลอยตัว (Hover) หมุนใบพัดแบบเรียลไทม์
- **แท็กฉากจริงในเกม**: ลานบิน • หุบเขาหิมะ • ทะเลสาบ • หมู่บ้าน
- **เมนูเลือก 4 โหมดหลัก**:
  1. **โหมดประกอบ**: เลือกชิ้นส่วน 8 จุด ดูค่า T/W, เวลาบิน, ราคา พร้อมบทเรียนทุกชิ้น
  2. **บินอิสระ**: บินสำรวจแผนที่ใหม่ ไม่มีเป้าหมาย ไม่จำกัดเวลา
  3. **ภารกิจ**: 3 ด่านวัดผลชุดที่ประกอบ
  4. **บทเรียนชิ้นส่วน**: ทำไมโครงต้องคาร์บอน ทำไมใบพัดต้องจับคู่ CW/CCW
- **แถบคำแนะนำคีย์ลัดด้านล่าง**: สรุปปุ่มควบคุม

### 2. โหมดประกอบ (Assembly Workbench - Tab 1)
- **3D Interactive Workbench**:
  - แสดงชิ้นส่วนโดรน 3D แบบแยกชิ้น (Modular 3D Model)
  - หมุนและซูมมุมมองได้ 360 องศา (Orbit Controls)
  - ปุ่มปรับมุมกล้อง 4 รูปแบบ:
    - **มุมเอียง (Isometric)**
    - **ผังบน (Top-down)**
    - **มุมหลัง (Rear view)**
    - **แยกชิ้นส่วน (Exploded View)**: อนิเมชันกระจายชิ้นส่วน 8 ชิ้นออกจากกันตามแกนความสูงและรัศมี ให้เห็นบอร์ด FC, ESC, โครงคาร์บอน, แบตเตอรี่, มอเตอร์ด้านในอย่างชัดเจน
- **แผงสรุปชุดที่ประกอบ (ซ้าย)**:
  - น้ำหนักรวม (Total Weight)
  - แรงยกทั้งหมด (Total Thrust)
  - อัตราส่วนแรงยก / น้ำหนัก (Thrust-to-Weight Ratio T/W)
  - เวลาบินประมาณ (Est. Flight Time)
  - กระแสที่ใช้ (Max Current)
  - ราคารวม (Total Price)
  - ตรวจสอบความเข้ากันได้ (Compatibility & Verification)
- **รายการ 8 ชิ้นส่วน (ขวา)**:
  - 01 โครงโดรน (Frame)
  - 02 มอเตอร์ (Motor)
  - 03 ใบพัด (Propeller)
  - 04 ESC (Electronic Speed Controller)
  - 05 แบตเตอรี่ (Battery)
  - 06 ชุดควบคุมการบิน (Flight Controller - FC)
  - 07 กล้อง / เพย์โหลด (Camera / Payload)
  - 08 GPS (GPS & Antenna)
  - คลิกชิ้นส่วนเพื่อเปิด Modal เลือกสเปก ดูราคา และอ่านบทเรียนวิศวกรรม

### 3. ตรวจความพร้อมก่อนบิน (Pre-Flight Check - Tab 2)
ระบบตรวจสอบชุดที่ประกอบเทียบกับความต้องการของแต่ละภารกิจ (Pass/Fail Checklist):
1. **ฝึกบินพื้นฐาน**: เช็กแรงยก (T/W ≥ 1.5), เวลาบิน (≥ 00:45), ไต่ระดับ (≥ 8 ม.)
2. **สำรวจพื้นที่เกษตร**: เช็กแรงยก (T/W ≥ 1.8), เพย์โหลดกล้อง (≥ 40 ก.), ระบบ GPS, เวลาบิน (≥ 01:30), ไต่ระดับ (≥ 18 ม.)
3. **ตรวจสอบเสาสูง**: เช็กแรงยกต้านลม (T/W ≥ 2.2), กล้องซูมความละเอียดสูง (≥ 100 ก.), เวลาบิน (≥ 01:10), ไต่ระดับความสูง (≥ 45 ม.)

### 4. เลือกภารกิจ (Mission Dispatch - Tab 3)
- **การ์ดใหญ่ "บินอิสระ FREE FLIGHT"**: สำหรับซ้อมบังคับ บินสำรวจได้ไม่มีจำกัดเวลา
- **3 ภารกิจหลัก**:
  - **ฝึกบินพื้นฐาน**: ลม 1.5 ม./วิ • เวลาจำกัด 02:00
  - **สำรวจพื้นที่เกษตร**: ลม 2.6 ม./วิ • เวลาจำกัด 03:30 (มีวงแหวน Checkpoint 4 จุดเหนือแปลงนา)
  - **ตรวจสอบเสาสูง**: ลม 5 ม./วิ • เวลาจำกัด 03:00 (ไต่ความสูงสู่ยอดเสาส่งสัญญาณ 45 ม.)

### 5. ระบบจำลองการบิน 3 มิติ (3D Flight Simulator - Tab 3 Launch)
- **ฉาก 3 มิติขนาดใหญ่**:
  - เทือกเขาหิมะ, ภูเขาหิน, เนินเขาเขียวชอุ่ม
  - ลานบิน (Runway), โรงเก็บเครื่องบิน (Hangar), อาคารหอบังคับการ (Control Tower) พร้อมเรดาร์และไฟสัญญาณ
  - ลานจอดฮอ "H" พร้อมวงแหวนเรืองแสงสีฟ้า
  - เสาวัดทิศทางลม (Windsock) ที่เอียงและแกว่งตามแรงลมของแต่ละภารกิจ
  - แปลงเกษตรกรรมและนาข้าว 4 ผืน, หมู่บ้านและบ้านเรือนหลังคาสีต่างๆ, ทะเลสาบ
  - เสาส่งสัญญาณโทรคมนาคมสูง 45 เมตร พร้อมไฟกระพริบสีแดงด้านบน
- **ระบบฟิสิกส์การบิน 6DOF (6 Degrees of Freedom)**:
  - แรงขับและแรงยกคำนวณตามมอเตอร์ ใบพัด และแรงดันแบตเตอรี่จริง
  - แรงโน้มถ่วง แรงต้านอากาศ และการดริฟต์ตามกระแสลม
  - การลงจอดและการชนพื้น
  - การกินไฟแบตเตอรี่แบบไดนามิก (เร่งเครื่องมากแบตลดไว)
- **ระบบเสียงสังเคราะห์ Web Audio API**:
  - เสียงมอเตอร์ Brushless 4 ตัวที่เปลี่ยนระดับเสียง (Pitch) และความดังตามคันเร่ง
  - เสียงปี๊บสถานะ ARM / เสียงเตือนเมื่อผ่าน Checkpoint
- **หน้าจอ HUD & Telemetry**:
  - กล่องแสดง ความสูง, ความเร็ว (กม./ชม.), เวลาบิน, จุดสำรวจ (Checkpoints), แบตเตอรี่คงเหลือ
  - **Flight Controller OSD (ล่างซ้าย)**:
    - หน้าปัดวัดระดับความเอียงเครื่อง (Artificial Horizon / Attitude Indicator)
    - จอยสติ๊กจำลองแสดงแกนโยกแบบเรียลไทม์
    - ปุ่มตัด/ต่อระบบเครื่องยนต์ (`ARM` / `RESET`)
  - ปุ่ม `ลงจอด` และ `← หน้าแรก`

### 6. บทเรียนชิ้นส่วน (Lessons - Tab 4)
- ตารางสรุปบทเรียนวิศวกรรมการบิน 8 ข้อ ละเอียดตามชิ้นส่วนที่ผู้ใช้เลือก:
  - เหตุผลที่โครงโดรนใช้คาร์บอนไฟเบอร์
  - การทำงานของมอเตอร์ Brushless, ค่า KV และการหักล้างทอร์ก CW/CCW
  - มุมบิด Pitch ของใบพัด และการเกิดแรงกดถ้าใส่สลับคู่
  - ความสำคัญของ ESC และการรับกระแส Amp
  - จุดสมดุลของน้ำหนักแบตเตอรี่ LiPo (ความสัมพันธ์ที่ไม่เป็นเส้นตรงระหว่างน้ำหนักกับเวลาบิน)
  - หน้าที่ของ Flight Controller, ไจโร และบารอมิเตอร์
  - โหลดเพย์โหลดของกล้องและกิมบอล
  - ความแม่นยำของ GPS และระบบ RTK ระดับเซนติเมตร

### 7. หน้าต่างสรุปผลการบิน (Flight Debrief Modal)
- แสดงเมื่อลงจอดหรือจบภารกิจ:
  - สถิติ: **เวลาที่ใช้**, **แบตเตอรี่เหลือ**, **ความสูงสุดที่ไต่ได้**
  - กล่องคำแนะนำ **"เรียนรู้จากเที่ยวบินนี้"**: วิเคราะห์ฟิสิกส์การบิน อัตราส่วน T/W และการกินกระแสไฟ เพื่อให้ผู้เรียนปรับแต่งเครื่องได้ดียิ่งขึ้น
  - ปุ่ม **"บินอีกรอบ"**, **"ไปทำภารกิจ →"**, **"กลับไปแก้ชุด"**

## ⌨️ ปุ่มควบคุมการบิน (Flight Controls)

| ปุ่ม | คำสั่ง | รายละเอียด |
| :--- | :--- | :--- |
| **Space** | เร่งคันเร่งขึ้น (Throttle Up) | เพิ่มความเร็วมอเตอร์ ไต่ระดับความสูง |
| **Shift** | ผ่อนคันเร่งลง (Throttle Down) | ลดรอบมอเตอร์ ลดระดับความสูง |
| **W / S** | หน้า - ถอยหลัง (Pitch) | เอียงหัวโดรนพุ่งไปข้างหน้า / ถอยหลัง |
| **A / D** | หันซ้าย - ขวา (Yaw) | หมุนรอบแกนตัวเองตามเข็ม/ทวนเข็ม |
| **Q / E** | เอียงข้างซ้าย - ขวา (Roll) | สไลด์เอียงซ้าย / เอียงขวา |
| **คลิกลากเมาส์** | หมุนมุมกล้อง | มองรอบโดรน 360 องศา |
| **C** | กล้องกลับหลังเครื่อง | รีเซ็ตมุมมองกล้องให้อยู่ท้ายโดรน |
| **V** | สลับมุมมอง FPV | สลับระหว่างมุมมองบุคคลที่ 3 และมุมมองกล้องหน้ารถ FPV |
| **H** | Altitude / Position Hold | ล็อกระดับความสูงและตำแหน่ง (ต้องมี GPS/Barometer) |
| **R** | Return to Home (RTH) | บินกลับจุดปล่อยตัวอัตโนมัติ |
